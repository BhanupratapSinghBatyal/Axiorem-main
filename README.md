Running Locally
1. Clone the repository
git clone https://github.com/<your-org>/axiorem.git
cd axiorem
2. Install dependencies
npm install
3. Configure environment variables

Create a .env file and add the required application credentials and service configuration.

# Example
DATABASE_URL=
API_KEY=
JWT_SECRET=

Never commit secrets or production credentials to the repository.

4. Start development
npm run dev
